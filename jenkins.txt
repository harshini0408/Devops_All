## AIM
To install Jenkins in cloud and configure Jenkins.

## PROCEDURE

### Step 1: Update Ubuntu

```bash
sudo apt update
```

### Step 2: Install Java 21

```bash
sudo apt install fontconfig openjdk-21-jre -y
```

Verify:

```bash
java -version
```

### Step 3: Create Keyrings Directory

```bash
sudo mkdir -p /etc/apt/keyrings
```

### Step 4: Download Jenkins Repository Key

```bash
sudo wget -O /etc/apt/keyrings/jenkins-keyring.asc \
https://pkg.jenkins.io/debian-stable/jenkins.io-2026.key
```

### Step 5: Add Jenkins Repository

```bash
echo "deb [signed-by=/etc/apt/keyrings/jenkins-keyring.asc] https://pkg.jenkins.io/debian-stable binary/" | sudo tee /etc/apt/sources.list.d/jenkins.list > /dev/null
```

### Step 6: Update Package List

```bash
sudo apt update
```

### Step 7: Install Jenkins

```bash
sudo apt install jenkins -y
```

### Step 8: Enable and Start Jenkins

```bash
sudo systemctl enable jenkins
sudo systemctl start jenkins
```

Check status:

```bash
sudo systemctl status jenkins
```

Expected output:

```text
Active: active (running)
```

### Step 9: Obtain Administrator Password

```bash
sudo cat /var/lib/jenkins/secrets/initialAdminPassword
```

Copy the displayed password.

### Step 10: Configure Jenkins in Browser

1. Open Firefox or Chrome.
2. Visit:

```text
http://localhost:8080
```

3. Enter the administrator password.
4. Click Continue.
5. Select **Install suggested plugins**.

### Step 11: Create Admin User

Enter:
- Username
- Password
- Full Name
- Email ID

Click **Save and Continue**.

### Step 12: Configure Jenkins URL

Enter:

```text
http://localhost:8080/
```

Click **Save and Finish**.

Click **Start using Jenkins**.

### RESULT

Thus, Jenkins was successfully installed and configured in Ubuntu.
